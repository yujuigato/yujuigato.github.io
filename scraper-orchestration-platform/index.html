Overview

做了什麼

爬蟲原本只能在本機手動執行，沒有排程、沒有隔離環境、也沒有版本紀錄。為此建置了一套自動化平台：

  • 以 Docker 將不同類型的爬蟲（輕量 API 型、需瀏覽器渲染型）分別容器化，各自獨立執行、互不干擾
  • 以 Apache Airflow 建立排程機制，定時自動觸發爬蟲任務，並設定失敗通知
  • 導入 GitLab 做版本控制，取代手動上傳檔案，讓程式碼異動有紀錄可查
  • 整理成標準化的部署流程，供後續維護與環境重建參考
